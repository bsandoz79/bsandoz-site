# Maquette

Écrans de référence exportés de la maquette Claude Design :
- `Main` : accueil ordinateur · `Mobile` : accueil mobile
- `Tarifs` : formules et simulateur
- `Configurateur` : composer mon site + aperçu en direct (contient la logique JS de référence)
- `Devis` : parcours de demande (étape 2)
- `RDV` : rendez-vous découverte gratuit
- `EspaceClient` : espace client

Ouvrir un fichier dans le navigateur ne marche pas tel quel (il dépend de l'éditeur de maquette) : lire le HTML comme référence de structure, de textes et de styles.
