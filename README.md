# bsandoz-site

Site freelance de Baptiste Sandoz (bsandoz.fr) : présentation des services, configurateur de projet avec aperçu en direct, demande de devis et prise de rendez-vous.

## Démarrer
```bash
cd front
npm install
npm run dev
```

## Scripts (dans `front/`)
| Commande | Rôle |
| --- | --- |
| `npm run dev` | serveur de développement |
| `npm run test` | tests unitaires et fonctionnels |
| `npm run lint` | analyse du code |
| `npm run build` | version de production dans `front/dist` |
